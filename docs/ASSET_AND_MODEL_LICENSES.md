# Asset and Model Licences

Version-controlled record required by plan §2.2. The backend `asset_registry` + `licences` tables are seeded from
`shared/asset-manifests/asset_manifest_v1.json`; this file is the human-reviewable mirror. **Do not ship an asset or
model until its licence has been reviewed** (see `docs/ADR/0005-asset-licensing-workflow.md`).

tone-babble voices are generated by code written by the CharacterVerse team. No third-party art, audio, fonts in
rendered output, or trained model weights are bundled. Provenance: in-house; acquisition date = commit date.

licence gate everywhere (catalogue, recipes, mixer, storyboards, previews).
